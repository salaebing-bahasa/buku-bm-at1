Keluarga Saya

Ini keluarga saya. Ini ayah saya. Ini ibu saya.

Ini abang saya. Ini kakak saya. Ini adik saya.

Saya sayang keluarga saya.

Pola ayat รูปประโยค

Ini + สมาชิก + saya → Ini ibu saya. (นี่คือแม่ของฉัน)

Latihan แบบฝึกหัด

  1. เขียนคำภาษามลายู

    1. พ่อ
    2. แม่
    3. พี่ชาย
    4. พี่สาว
    5. น้อง
    ดูเฉลย

    ayah, ibu, abang, kakak, adik

  2. เรียงคำให้เป็นประโยค

    1. saya / ini / ayah →
    2. ibu / saya / ini →
    ดูเฉลย

    Ini ayah saya. / Ini ibu saya.

  3. วาดภาพครอบครัวของตนเอง แล้วแนะนำให้เพื่อนฟังด้วยประโยค "Ini ... saya."
