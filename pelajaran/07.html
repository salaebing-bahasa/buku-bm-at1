Keluarga Saya

Ini keluarga saya. Ini ayah saya. Ini ibu saya.

Ini abang saya. Ini kakak saya. Ini adik saya.

Saya sayang keluarga saya.

Pola ayatรูปประโยค

Ini + ahli keluarga + saya → Ini ibu saya.Ini + สมาชิก + saya → Ini ibu saya. (นี่คือแม่ของฉัน)

Latihanแบบฝึกหัด

  1. Tulis perkataan bahasa Melayu.เขียนคำภาษามลายู

    1. พ่อ
    2. แม่
    3. พี่ชาย
    4. พี่สาว
    5. น้อง
    Lihat jawapanดูเฉลย

    ayah, ibu, abang, kakak, adik

  2. Susun perkataan menjadi ayat.เรียงคำให้เป็นประโยค

    1. saya / ini / ayah →
    2. ibu / saya / ini →
    Lihat jawapanดูเฉลย

    Ini ayah saya. / Ini ibu saya.

  3. Lukis gambar keluarga kamu, kemudian perkenalkan kepada rakan dengan ayat "Ini ... saya."วาดภาพครอบครัวของตนเอง แล้วแนะนำให้เพื่อนฟังด้วยประโยค "Ini ... saya."

Nilai Murniข้อคิด

Islam mengajar kita supaya taat dan berbuat baik kepada ibu bapa (birrul walidain) serta menyayangi adik-beradik dalam keluarga.

อิสลามสอนให้เราเชื่อฟังและทำดีต่อพ่อแม่ (birrul walidain) และรักพี่น้องในครอบครัว
