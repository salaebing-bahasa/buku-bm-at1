Objektif Pembelajaranจุดประสงค์การเรียนรู้

  • ออกเสียงสระรูมี a, e, i, o, u ได้ถูกต้อง
  • รู้จักอักษรยาวีที่ใช้แทนเสียงสระ คือ ا و ي
  • บอกสระจากการฟังคำได้

Vokal Rumiสระอักษรรูมี

ภาษามลายูอักษรรูมีมีสระ 5 ตัว คือ a e i o u

สระเสียงตัวอย่างคำความหมาย
A a/อา/apiไฟ
E e/เออ/ หรือ /เอ/emakแม่
I i/อี/ikanปลา
O o/โอ/orenส้ม
U u/อู/ularงู

Vokal Jawiสระอักษรยาวี

อักษรยาวีใช้ 3 ตัวนี้แทนเสียงสระ

อักษรยาวีชื่อแทนเสียงตัวอย่าง
اalifaapi اڤي
وwauo, uular اولر
يyae (เอ), iibu ايبو

Latihanแบบฝึกหัด

  1. ฟังครูอ่านคำ แล้วเขียนสระตัวแรกของคำ

    1. api →
    2. ikan →
    3. ular →
    4. emak →
    5. oren →
    Lihat jawapanดูเฉลย

    a, i, u, e, o

  2. เติมสระ a, e, i, o, u ให้เป็นคำที่ถูกต้อง

    1. b__ku (หนังสือ)
    2. k__ki (เท้า)
    3. __bu (แม่)
    4. m__ta (ตา)
    5. __ren (ส้ม)
    Lihat jawapanดูเฉลย

    buku, kaki, ibu, mata, oren

  3. จับคู่กับคู่ อ่านคำให้เพื่อนฟัง แล้วสลับกัน

    1. api • ayam • ikan • ibu • ular • ubi
